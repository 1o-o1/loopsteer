# Planned n per cell (PLANNED, not measured)

Generated by cluster/gen_jobs.py. One pool file per dataset for every model (RA-20 item 9): every candidate
of the pool is scanned and every item that passes the model's clean filter is kept; no per-model cap.
latest_kept is the last pilot run's kept count (those runs had quotas); planned_n is the pool times the
pass rate of that run. The run itself decides every n.

Generation (grid A): scored = every problem that passes both clean filters. This week's runs (GSM8K run 1
and run 5, SVAMP) scored 150: prep_a orders the pool problems that SETTLE answers correctly by a seeded
shuffle (random.Random("k17_gen:20261007") over the sorted problem ids, steer_gen.shuffled), screens the
first n_screen of that order (240, extended by 80) on the B side (A side from the SETTLE cell), and select_a
keeps the first 150 in that shuffled order that pass both; the 22 sentinels are the prep items left over
nearest the prompt-length quantiles of the scored set, the 8 shift rows the shortest GSM8K eval prompts
outside both sets. Not by id and not by length: by the seeded shuffle order.

CF (CounterFact): CounterFact pool of the cluster run: the 3,741 candidate pairs the production CF builder made from cf_records.json (prod/steer/data.py build_cf, then the runner's pos0 = exclude). The filters are applied on the Ouro tokenizer (ByteDance/Ouro-1.4B tokenizer.json, no BOS), not before tokenization: (1) records of relations P17, P103, P364, P641, P176 with at least one paraphrase prompt, split by subject half (int(sha256('cf-split:' + subject)[:8], 16) % 2; 0 = dev, 1 = test; pairs only inside a half); (2) the answer ' ' + target_true is one Ouro token; (3) pairs within one relation and one prompt template, record A paired with the next records of the template in case-id order, at most 5 partners per record A (window 5), skipping pairs whose Ouro prompts differ in length, whose answer tokens are equal, whose subjects are equal, or whose differing token span (common prefix and suffix removed) is empty or of unequal length: 9,125 pairs; (4) pos0 = exclude: pairs whose differing span starts at position 0 of the Ouro prompt (the subject opens the prompt) are removed: 5,384 removed, 3,741 kept. No sampling, cap or quota. On another tokenizer a pair is kept when its answers are single, different tokens and prompts A and B have equal length with an aligned source span (cluster/pilot/cf_pool.py); the model's own clean filter follows.
